# 📝 Daily Task List
مه
A simple and practical application for managing your daily tasks, built with pure HTML, CSS, and JavaScript. This project is an excellent example for understanding core concepts like **DOM Manipulation**, **Event Handling**, and **CRUD** operations in JavaScript.

## ✨ Features
Live:https://amirhaghi1998-del.github.io/ToDo/
- **➕ Add Task** – Type your task and click the **Add** button or simply press the **Enter** key.
- **✅ Mark as Complete** – Click on any task text to toggle its status (strikethrough will appear). Click again to undo.
- **🗑️ Delete Task** – Each task comes with a **Delete** button. A simple confirmation dialog prevents accidental removals.
- **📱 Responsive Design** – Clean and functional layout on mobile, tablet, and desktop devices.
- **🎨 Modern & Minimal UI** – Features smooth gradients, soft shadows, and subtle animations for a pleasant user experience.

## 🛠️ Technologies Used

- **HTML5** – Page structure and semantics.
- **CSS3** – Styling using Flexbox, gradients, transitions, and custom scrollbars.
- **JavaScript (ES6+)** – Application logic, event listeners, and dynamic DOM updates.
